● Project overview

StyleCraft — AI Email Automation

A full-stack support-inbox automation platform: AI email classification, a local RAG knowledge pipeline, a visual rule builder, and human-in-the-loop auto-reply dispatch.

This page is a static landing page only. The actual application is a Next.js full-stack app with server-side API routes, a Prisma/SQLite database, IMAP/SMTP integrations, and LLM calls — it requires a real Node.js server and cannot run on GitHub Pages. Clone the repo and run it locally, or deploy it to a Node-capable host (Vercel, Render, Railway, or the included Docker image).

AI Processing Pipeline

Language detection, category tagging, sentiment, urgency, spam and duplicate checks.

Local RAG Service

Token-overlap and TF-IDF matching against uploaded knowledge base documents.

Visual Rule Builder

Conditional automation rules that route, template-match, and escalate emails.

Human Approval Flow

Fully automatic, draft-for-approval, or fully manual reply dispatch modes.

Run it locally

npm install
npx prisma generate
npx prisma db push
npx tsx prisma/seed.ts
npm run dev
